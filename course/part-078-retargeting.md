## Step 781: ทำไม Retargeting มักให้ ROAS สูงกว่าโฆษณาหากลุ่มเป้าหมายใหม่

Retargeting คือการยิงโฆษณาไปยังคนที่ **เคยมีปฏิสัมพันธ์กับธุรกิจของคุณมาก่อน** (เข้าเว็บไซต์, ดูวิดีโอ, ใส่ตะกร้าแต่ไม่ซื้อ) ซึ่งมีความคุ้นเคยและความสนใจอยู่แล้ว

### เปรียบเทียบต้นทุนและ Conversion
```
โฆษณาหากลุ่มเป้าหมายใหม่ (Cold Audience): ต้องสร้างความสนใจจากศูนย์ Conversion Rate ต่ำกว่า
โฆษณา Retargeting (Warm/Hot Audience): มีความสนใจอยู่แล้ว Conversion Rate สูงกว่ามาก
```

**หลักการสำคัญ:** เชื่อมโยงกับ Meta Pixel/TikTok Pixel (Part 072 Step 722, Part 073 Step 735) ที่ต้องตั้งค่าไว้ล่วงหน้า เพื่อสร้างกลุ่ม Retargeting ได้

---

## Step 782: การแบ่งกลุ่ม Retargeting ตามพฤติกรรม

### ระดับความอุ่น (Temperature) ของกลุ่มเป้าหมาย
```markdown
| กลุ่ม | พฤติกรรม | ระดับความสนใจ |
|---|---|---|
| **Warm** | เคยดูวิดีโอ/เข้าเว็บไซต์ แต่ไม่ได้ดูสินค้าเจาะจง | ปานกลาง |
| **Hot** | ดูหน้าสินค้าเจาะจง/ใส่ตะกร้าแต่ไม่ซื้อ | สูง |
| **Very Hot** | เริ่มขั้นตอนชำระเงินแต่ไม่จบ (Checkout Abandonment) | สูงที่สุด |
```

**หลักการสำคัญ:** ยิ่งกลุ่มเป้าหมาย "อุ่น" มากเท่าไหร่ ควรใช้ข้อความโฆษณาที่เจาะจงและกระตุ้นการตัดสินใจมากขึ้นเท่านั้น (เช่น กลุ่ม Very Hot ควรได้ข้อเสนอส่วนลด/ความเร่งด่วนที่ชัดเจน)

---

## Step 783: การออกแบบโฆษณา Retargeting ที่แตกต่างจากโฆษณาทั่วไป

### หลักการออกแบบโฆษณาตามกลุ่มเป้าหมาย
```markdown
สำหรับกลุ่ม Warm: เน้นให้ความรู้/สร้างความไว้วางใจเพิ่ม (คล้ายเนื้อหา Organic)
สำหรับกลุ่ม Hot: แสดงสินค้าที่เคยดูอีกครั้ง + Social Proof (รีวิว)
สำหรับกลุ่ม Very Hot: เสนอส่วนลด/ความเร่งด่วน ("ตะกร้าของคุณกำลังจะหมดอายุ")
```

### ตัวอย่างโฆษณา Retargeting สำหรับ Cart Abandonment
```markdown
"ยังคิดอยู่ใช่ไหม? 🤔
[ชื่อสินค้า] ที่คุณเลือกไว้ยังรออยู่ในตะกร้า
รับส่วนลดพิเศษ 10% เมื่อสั่งซื้อภายใน 24 ชม. นี้"
```

---

## Step 784: การกำหนด Frequency Cap (จำกัดความถี่การเห็นโฆษณา)

การเห็นโฆษณาเดิมซ้ำมากเกินไปทำให้ผู้ใช้รำคาญและอาจส่งผลเสียต่อภาพลักษณ์แบรนด์

### หลักการกำหนด Frequency Cap
```
Retargeting ทั่วไป: จำกัดไม่เกิน 3-5 ครั้ง/สัปดาห์ต่อคน
Retargeting ระยะยาว (Warm Audience): ความถี่ต่ำกว่า เพื่อไม่ให้รู้สึกถูกตาม
```

---

## Step 785: การทำ Win-back Campaign สำหรับลูกค้าเก่าที่หายไป

Win-back Campaign คือการดึงลูกค้าที่เคยซื้อแต่ไม่ได้ซื้อซ้ำมานาน กลับมาซื้ออีกครั้ง

### วิธีระบุลูกค้าที่ควรทำ Win-back
```markdown
ลูกค้าที่ไม่ได้ซื้อซ้ำภายใน [ระยะเวลาเฉลี่ยระหว่างการซื้อของลูกค้าทั่วไป × 1.5-2 เท่า]

ตัวอย่าง: ลูกค้าทั่วไปซื้อซ้ำเฉลี่ยทุก 30 วัน
→ ลูกค้าที่ไม่ซื้อเกิน 45-60 วัน ควรอยู่ใน Win-back List
```

### เทมเพลตข้อความ Win-back
```markdown
"เราคิดถึงคุณนะคะ/ครับ! 💛
ไม่เห็นคุณมานานเลย รับส่วนลดพิเศษ 15% สำหรับการสั่งซื้อครั้งต่อไป
[ลิงก์]"
```

## Step 786: การใช้ Custom Audience จาก Email List สำหรับ Retargeting

Email List (Part 027) สามารถอัปโหลดเข้าแพลตฟอร์มโฆษณาเพื่อสร้าง Custom Audience และยิงโฆษณาเจาะจงกลุ่มนี้โดยตรง

### ประโยชน์
- เข้าถึงลูกค้าเดิมผ่านโฆษณาแม้ไม่ได้เปิดอีเมล
- สร้าง Lookalike Audience จากลูกค้าคุณภาพดีที่มีอยู่แล้ว (Part 072 Step 723)

## Step 787: การวัดผล Retargeting Campaign แยกจากโฆษณาทั่วไป

### เทมเพลตเปรียบเทียบ
```markdown
| ประเภทแคมเปญ | งบที่ใช้ | ROAS | CPA |
|---|---|---|---|
| Cold Audience | | | |
| Retargeting - Warm | | | |
| Retargeting - Hot | | | |
| Win-back | | | |
```

การแยกวัดผลนี้ช่วยให้เห็นว่าควรจัดสรรงบเท่าไหร่ระหว่างการหาลูกค้าใหม่กับการดึงลูกค้าเก่ากลับมา

---

## Step 788: การจัดสรรงบระหว่างหากลุ่มเป้าหมายใหม่กับ Retargeting

### แนวทางจัดสรรงบทั่วไป (ปรับตามผลลัพธ์จริง)
```markdown
70-80% ของงบ: หากลุ่มเป้าหมายใหม่ (Cold Audience) — เพื่อการเติบโตต่อเนื่อง
20-30% ของงบ: Retargeting — เพื่อเพิ่ม Conversion Rate จากคนที่สนใจอยู่แล้ว
```

**ข้อคิดสำคัญ:** สัดส่วนนี้ปรับได้ตามผลลัพธ์จริง ถ้า Retargeting ให้ ROAS สูงกว่ามากและมีกลุ่มเป้าหมายเพียงพอ อาจเพิ่มสัดส่วนได้ แต่ต้องมี Cold Audience เพียงพอเพื่อสร้างกลุ่ม Retargeting ใหม่อย่างต่อเนื่อง

---

## Step 789: กรณีศึกษา — Retargeting ที่กู้ยอดขายจากตะกร้าที่ถูกทิ้ง

**สถานการณ์:** ผู้เรียนคนหนึ่งมีอัตรา Cart Abandonment สูงถึง 75% (จาก Part 054 Step 537) แม้จะมี Cart Recovery Email แล้ว แต่ยังมีลูกค้าจำนวนมากที่ไม่เปิดอีเมล

**การปรับ:** เพิ่ม Retargeting Ads เฉพาะกลุ่ม Very Hot (Checkout Abandonment) บน Facebook ควบคู่กับ Cart Recovery Email พร้อมข้อเสนอส่วนลด 10% ภายใน 24 ชม.

**ผลลัพธ์:** กู้ยอดขายที่เคยเสียไปได้เพิ่มขึ้น 18% จากกลุ่มนี้ ด้วย ROAS ของแคมเปญ Retargeting ที่สูงถึง 8x (สูงกว่าแคมเปญหากลุ่มเป้าหมายใหม่มาก)

**บทเรียน:** การใช้ Retargeting ควบคู่กับ Email Automation (มากกว่าใช้อย่างใดอย่างหนึ่ง) ช่วยเพิ่มโอกาสกู้ยอดขายที่เกือบเสียไปได้อย่างมีประสิทธิภาพ
