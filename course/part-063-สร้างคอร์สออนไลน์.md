# Part 063 — สร้างคอร์สออนไลน์ตั้งแต่คิดหลักสูตรถึงอัดวิดีโอ

> **หมวด G: สินค้าดิจิทัลและธุรกิจซอฟต์แวร์**
> **ครอบคลุม Step 621–630 จากทั้งหมด 1000 Step**

---

## เป้าหมายของตอนนี้

1. เรียนรู้กระบวนการออกแบบหลักสูตร (Curriculum Design) ที่มีประสิทธิภาพ
2. เข้าใจโครงสร้างคอร์สที่ทำให้ผู้เรียนเรียนจบและได้ผลลัพธ์จริง
3. เรียนรู้เทคนิคอัดวิดีโอสอนด้วยงบประมาณจำกัด
4. เข้าใจการออกแบบแบบฝึกหัด/การประเมินผลในคอร์ส
5. วางแผนโครงสร้างราคาคอร์สออนไลน์

---

## Step 621: กระบวนการออกแบบหลักสูตร (Curriculum Design)

### ขั้นตอนออกแบบหลักสูตรแบบ Backward Design
```
1. กำหนดผลลัพธ์สุดท้าย — ผู้เรียนจบคอร์สแล้วต้องทำอะไรได้
2. แตกย่อยเป็นทักษะ/ความรู้ย่อยที่ต้องมีเพื่อไปถึงผลลัพธ์นั้น
3. จัดลำดับทักษะย่อยจากง่ายไปยาก (Learning Path)
4. แปลงแต่ละทักษะย่อยเป็นบทเรียน (Module/Lesson)
5. ออกแบบแบบฝึกหัด/การประเมินผลสำหรับแต่ละบทเรียน
```

**หลักการสำคัญ:** การออกแบบแบบ "เริ่มจากผลลัพธ์สุดท้าย" (Backward Design) ช่วยให้หลักสูตรมีเป้าหมายชัดเจน ไม่ใช่แค่รวมความรู้ทุกอย่างที่มีโดยไม่มีทิศทาง

---

## Step 622: โครงสร้างคอร์สที่ทำให้ผู้เรียนเรียนจบและได้ผลลัพธ์จริง

### ปัญหาที่พบบ่อยที่สุดของคอร์สออนไลน์: อัตราเรียนจบต่ำ
คอร์สออนไลน์ส่วนใหญ่มีอัตราผู้เรียนที่เรียนจบต่ำมาก เพราะบทเรียนยาวเกินไปหรือไม่มีโครงสร้างที่ชัดเจน

### หลักการออกแบบที่เพิ่มอัตราเรียนจบ
1. **แบ่งบทเรียนเป็นชิ้นเล็ก (Micro-learning)** — วิดีโอ 5-15 นาทีต่อบท ดีกว่าวิดีโอยาว 1-2 ชั่วโมง
2. **มีแบบฝึกหัดที่ลงมือทำได้ทันทีหลังแต่ละบท** — ไม่ใช่แค่ดูอย่างเดียว
3. **แสดงความคืบหน้าให้ผู้เรียนเห็น (Progress Bar)** — สร้างแรงจูงใจให้เรียนต่อ
4. **มีเช็คพอยต์/รางวัลระหว่างทาง** — เช่น Certificate ย่อยเมื่อจบแต่ละโมดูล


## Step 624: เทคนิคอัดวิดีโอสอนด้วยงบประมาณจำกัด

### รูปแบบวิดีโอสอนที่ใช้ได้ผลและทำง่าย
| รูปแบบ | อุปกรณ์ที่ต้องใช้ | เหมาะกับ |
|---|---|---|
| **หน้าจอ + เสียงบรรยาย (Screen Recording)** | โปรแกรมอัดหน้าจอ (OBS Studio - ฟรี) + ไมค์พื้นฐาน | สอนซอฟต์แวร์/ทักษะที่ทำผ่านคอมพิวเตอร์ |
| **หน้ากล้อง (Talking Head)** | มือถือ/กล้อง + ไมค์ + แสงพื้นฐาน (Part 023 Step 225) | สอนแนวคิด/ทฤษฎีที่ต้องการความน่าเชื่อถือส่วนตัว |
| **สไลด์ + เสียงบรรยาย** | Canva/PowerPoint + โปรแกรมอัดเสียง | เนื้อหาที่มีโครงสร้างชัดเจน ไม่ต้องการหน้ากล้อง |

### เครื่องมืออัดหน้าจอฟรี
**OBS Studio** เป็นโปรแกรมอัดหน้าจอฟรีที่ทรงพลัง ใช้ได้ทั้งอัดหน้าจอเดี่ยวหรือรวมหน้ากล้องตัวเองไปด้วย

---

## Step 625: การออกแบบแบบฝึกหัด/การประเมินผลในคอร์ส

### ประเภทแบบฝึกหัดที่ใช้ได้ผล
1. **Action Item** — งานที่ต้องลงมือทำจริงหลังดูวิดีโอ (เชื่อมโยงกับรูปแบบ Action Items ที่ใช้ตลอดหลักสูตรนี้)
2. **Quiz สั้นๆ** — ทดสอบความเข้าใจก่อนไปบทถัดไป
3. **โปรเจกต์ปลายทาง (Capstone Project)** — งานสุดท้ายที่รวมทักษะทั้งหมดที่เรียนมา

---

## Step 626: การเลือกแพลตฟอร์มโฮสต์วิดีโอคอร์ส

| แพลตฟอร์ม | ลักษณะเด่น |
|---|---|
| **Teachable/Thinkific** | สร้างคอร์สแบบครบวงจร มีระบบชำระเงินในตัว |
| **YouTube (Unlisted/Private)** | ฟรี แต่ต้องมีระบบจัดการการเข้าถึงแยกต่างหาก |
| **แพลตฟอร์มคอร์สไทย** | เข้าถึงฐานลูกค้าไทยที่มองหาคอร์สอยู่แล้ว (จะเจาะลึกใน Part 064) |
| **Vimeo (แบบมีรหัสผ่าน)** | คุณภาพวิดีโอดี ควบคุมการเข้าถึงได้ |

## Step 627: การทดสอบคอร์สกับกลุ่มเล็กก่อนเปิดขายจริง (Beta Test)

### วิธีทำ Beta Test
```
1. คัดเลือกผู้เรียนกลุ่มเล็ก (5-10 คน) จากผู้ติดตาม/คนรู้จัก
2. ให้เรียนฟรีหรือราคาพิเศษมาก แลกกับ Feedback ที่ตรงไปตรงมา
3. สังเกตว่าผู้เรียนติดขัดที่จุดไหน เข้าใจง่าย/ยากตรงไหน
4. ปรับปรุงเนื้อหาตาม Feedback ก่อนเปิดขายราคาจริง
```

**ประโยชน์เพิ่มเติม:** ผู้เรียน Beta Test ที่พอใจมักกลายเป็นรีวิว/Testimonial แรกที่ใช้ในการตลาดเปิดตัวจริง

---

## Step 628: การวางแผนโครงสร้างราคาคอร์สออนไลน์

### แนวทางตั้งราคาตามความลึกของคอร์ส
| ระดับคอร์ส | ช่วงราคาที่แนะนำ |
|---|---|
| คอร์สสั้น (Mini-course, 1-2 ชม.) | 300-900 บาท |
| คอร์สมาตรฐาน (3-8 ชม.) | 1,000-3,500 บาท |
| คอร์สครบวงจร (8+ ชม. พร้อมชุมชน/ที่ปรึกษา) | 3,500-15,000+ บาท |

**เชื่อมโยงกับ Value-based Pricing (Part 013 Step 124):** ราคาคอร์สที่ช่วยให้ผู้เรียนสร้างรายได้/แก้ปัญหาที่มีมูลค่าสูง สามารถตั้งราคาสูงได้ตามมูลค่าที่ส่งมอบ ไม่ใช่แค่ตามความยาววิดีโอ

---

## Step 629: กรณีศึกษา — คอร์สออนไลน์แรกที่ขายได้จากการทำ Beta Test

**สถานการณ์:** ผู้เรียนคนหนึ่งเป็นฟรีแลนซ์กราฟิกดีไซน์ (จากหมวด B) ต้องการสร้างคอร์สสอน Canva สำหรับเจ้าของธุรกิจขนาดเล็ก

**การพัฒนา:** ทำ Beta Test กับผู้เรียน 8 คนจากกลุ่ม Facebook ที่เกี่ยวข้อง ได้ Feedback ว่าเนื้อหาบางส่วนเร็วเกินไปสำหรับมือใหม่ จึงปรับเพิ่มบทเรียนพื้นฐานก่อนเข้าเนื้อหาหลัก

**ผลลัพธ์:** เมื่อเปิดขายจริงในราคา 1,290 บาท พร้อมรีวิวจากผู้เรียน Beta Test ทั้ง 8 คน ขายได้ 35 คนในเดือนแรก สร้างรายได้กว่า 45,000 บาท

**บทเรียน:** การทำ Beta Test ไม่เพียงช่วยปรับปรุงคุณภาพคอร์ส แต่ยังสร้างรีวิวแรกที่ทรงพลังสำหรับการตลาดตอนเปิดขายจริง
