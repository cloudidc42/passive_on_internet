# Part 072 — Facebook/Instagram Ads ตั้งแต่สร้างแคมเปญแรก

> **หมวด H: โฆษณาแบบเสียเงินและระบบ Funnel การขาย**
> **ครอบคลุม Step 721–730 จากทั้งหมด 1000 Step**

---

## เป้าหมายของตอนนี้

1. เข้าใจโครงสร้างบัญชีโฆษณา Facebook/Instagram (Campaign, Ad Set, Ad)
2. เรียนรู้การตั้งค่า Meta Pixel เพื่อ Tracking ที่แม่นยำ
3. เข้าใจตัวเลือกการเจาะกลุ่มเป้าหมาย (Targeting) ที่มีประสิทธิภาพ
4. เรียนรู้การเลือกวัตถุประสงค์แคมเปญ (Campaign Objective) ที่เหมาะกับเป้าหมาย
5. สร้างแคมเปญโฆษณาแรกอย่างเป็นระบบ

---

## Step 721: โครงสร้างบัญชีโฆษณา Facebook/Instagram

```
Campaign (แคมเปญ) — กำหนดวัตถุประสงค์หลัก (เช่น "เพิ่มยอดขาย")
    │
    ├─► Ad Set 1 (ชุดโฆษณา) — กำหนดกลุ่มเป้าหมาย, งบ, ตำแหน่งแสดงผล
    │       ├─► Ad 1.1 (โฆษณา) — ภาพ/วิดีโอ + ข้อความ
    │       └─► Ad 1.2
    └─► Ad Set 2 — กลุ่มเป้าหมายอื่น
            └─► Ad 2.1
```

**หลักการสำคัญ:** ใช้ 1 Campaign ต่อ 1 วัตถุประสงค์ แต่สามารถมีหลาย Ad Set ที่ทดสอบกลุ่มเป้าหมายต่างกัน และหลาย Ad ในแต่ละ Ad Set ที่ทดสอบครีเอทีฟต่างกัน (ตามแผนทดสอบจาก Part 071 Step 719)

---

## Step 722: การตั้งค่า Meta Pixel เพื่อ Tracking ที่แม่นยำ

Meta Pixel คือโค้ดที่ติดตั้งบนเว็บไซต์เพื่อติดตามพฤติกรรมผู้ใช้ที่มาจากโฆษณา Facebook/Instagram

### ขั้นตอนตั้งค่า Meta Pixel
```
1. สร้าง Pixel ใน Meta Business Suite
2. ติดตั้งโค้ด Pixel บนเว็บไซต์ (ทุกหน้า) — ผ่าน Plugin (WooCommerce) หรือ App (Shopify)
3. ตั้งค่า Event ที่สำคัญ (ViewContent, AddToCart, Purchase)
4. ทดสอบว่า Pixel ทำงานถูกต้องด้วย Meta Pixel Helper (Browser Extension)
```

**ทำไมสำคัญ:** Pixel ช่วยให้ระบบโฆษณา "เรียนรู้" ว่าใครมีโอกาสซื้อสูง และช่วยให้ทำ Retargeting ได้ (จะเจาะลึกใน Part 078)

---

## Step 723: ตัวเลือกการเจาะกลุ่มเป้าหมาย (Targeting)

### ประเภทการเจาะกลุ่มเป้าหมายหลัก
| ประเภท | อธิบาย |
|---|---|
| **Core Audience** | เจาะตามอายุ เพศ ที่อยู่ ความสนใจ พฤติกรรม |
| **Custom Audience** | เจาะกลุ่มคนที่มีข้อมูลอยู่แล้ว (Email List จาก Part 027, คนที่เข้าเว็บไซต์) |
| **Lookalike Audience** | ให้ระบบหาคนที่มีลักษณะคล้ายกับลูกค้าเดิม/Custom Audience |

**คำแนะนำสำหรับมือใหม่:** เริ่มจาก Core Audience ที่เจาะจงตาม Customer Avatar (Part 005) ก่อน เมื่อมีข้อมูลลูกค้าเพียงพอ (100+ คน) ค่อยสร้าง Lookalike Audience เพื่อขยายผล

---

## Step 724: การเลือกวัตถุประสงค์แคมเปญ (Campaign Objective)

| วัตถุประสงค์ | เหมาะกับ |
|---|---|
| **Awareness (การรับรู้)** | สร้างการรู้จักแบรนด์ใหม่ |
| **Traffic (การเข้าชม)** | ดึงคนเข้าเว็บไซต์/หน้า Landing Page |
| **Engagement (การมีส่วนร่วม)** | เพิ่มไลก์/คอมเมนต์/แชร์ |
| **Leads (การหาลูกค้าเป้าหมาย)** | เก็บข้อมูลติดต่อ (เชื่อมโยง Lead Magnet Part 027) |
| **Sales/Conversions (การขาย)** | กระตุ้นให้ซื้อสินค้า/บริการโดยตรง |

**หลักการสำคัญ:** เลือกวัตถุประสงค์ให้ตรงกับเป้าหมายจริงของแคมเปญ ระบบ Facebook จะปรับการแสดงผลให้เหมาะกับวัตถุประสงค์นั้น การเลือกผิดจะทำให้ได้ผลลัพธ์ที่ไม่ตรงกับที่ต้องการ

---

## Step 725: การสร้างครีเอทีฟโฆษณาที่ได้ผล

### หลักการสร้างครีเอทีฟที่ดึงดูด (เชื่อมโยง Part 006, 024)
1. **Hook 3 วินาทีแรกสำคัญที่สุด** — เหมือนหลักการวิดีโอสั้นจาก Part 024
2. **ใช้วิดีโอมากกว่าภาพนิ่งเมื่อเป็นไปได้** — มักได้ Engagement สูงกว่า
3. **ข้อความสั้นกระชับ ตรงประเด็น** — คนเลื่อนผ่านโฆษณาเร็ว
4. **มี Call-to-Action ที่ชัดเจน** (เชื่อมโยง Part 006 Step 57)

---

## Step 726: การตั้งงบและระยะเวลาแคมเปญ

### ตัวเลือกการตั้งงบ
| ประเภท | อธิบาย |
|---|---|
| **Daily Budget** | งบต่อวัน ระบบใช้จ่ายสม่ำเสมอทุกวัน |
| **Lifetime Budget** | งบรวมทั้งแคมเปญ ระบบกระจายใช้เองตามช่วงเวลาที่เหมาะสม |

**คำแนะนำสำหรับการทดสอบเบื้องต้น:** ใช้ Daily Budget เพื่อควบคุมและติดตามผลได้ง่ายกว่า (เชื่อมโยงกับแผนทดสอบ Part 071 Step 716)

---

## Step 727: ระยะเวลา Learning Phase ที่ต้องเข้าใจ

Facebook Algorithm ต้องใช้เวลา "เรียนรู้" ว่าใครคือกลุ่มที่มีโอกาสเปลี่ยนเป็นลูกค้าสูงที่สุด ในช่วงนี้ผลลัพธ์อาจยังไม่แม่นยำ/มีต้นทุนสูงกว่าปกติ

### หลักการรับมือ Learning Phase
1. **อย่าปรับแคมเปญบ่อยเกินไปในช่วงนี้** — การปรับบ่อยทำให้ระบบต้องเริ่มเรียนรู้ใหม่ (Reset Learning Phase)
2. **ให้เวลาอย่างน้อย 3-7 วัน หรือ 50 Conversions** ก่อนตัดสินใจว่าแคมเปญนี้ได้ผลหรือไม่
3. **ตั้งงบให้เพียงพอสำหรับการเรียนรู้** — งบน้อยเกินไปอาจทำให้ไม่ผ่าน Learning Phase เลย

## Step 729: กรณีศึกษา — แคมเปญแรกที่ได้ผลจากการทดสอบ Targeting

**สถานการณ์:** ผู้เรียนคนหนึ่งสร้างแคมเปญขายสินค้า E-Commerce (Part 041-050) โดยใช้ Core Audience แบบกว้าง (อายุ 18-65 ทั่วประเทศ) ผลลัพธ์ ROAS ต่ำกว่า 1

**การปรับ:** เจาะจง Targeting ตาม Customer Avatar ที่แท้จริง (อายุ 25-40, ความสนใจเฉพาะที่เกี่ยวกับสินค้า) และสร้าง Custom Audience จากคนที่เคยเข้าเว็บไซต์แล้ว

**ผลลัพธ์:** ROAS เพิ่มขึ้นเป็น 3.5x เพราะโฆษณาไปถึงกลุ่มคนที่มีโอกาสซื้อจริงมากกว่า แทนการยิงแบบกว้างที่สิ้นเปลืองงบไปกับคนที่ไม่สนใจ

**บทเรียน:** การเจาะจง Targeting ให้ตรงกับ Customer Avatar มีผลต่อ ROAS มากกว่าการปรับครีเอทีฟหรือเพิ่มงบในหลายกรณี
