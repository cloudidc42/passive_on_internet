# Part 049 — โปรโมชันและแคมเปญเทศกาลลดราคา (11.11, 12.12)

> **หมวด E: E-Commerce พื้นฐาน**
> **ครอบคลุม Step 481–490 จากทั้งหมด 1000 Step**

---

## เป้าหมายของตอนนี้

1. เข้าใจปฏิทินเทศกาลสำคัญของ E-Commerce ไทยตลอดทั้งปี
2. เรียนรู้การวางแผนแคมเปญล่วงหน้าอย่างเป็นระบบ
3. เข้าใจการคำนวณโปรโมชันที่ไม่ทำให้ขาดทุน
4. เรียนรู้เทคนิคเพิ่มยอดขายช่วงเทศกาลนอกเหนือจากการลดราคา
5. วางแผนหลังแคมเปญเพื่อรักษาลูกค้าที่ได้มา

## Step 481: ปฏิทินเทศกาลสำคัญของ E-Commerce ไทยตลอดปี

```markdown
| เดือน | เทศกาล/แคมเปญ | ลักษณะ |
|---|---|---|
| มกราคม | ปีใหม่ | เริ่มต้นปี, เป้าหมายใหม่ |
| กุมภาพันธ์ | วาเลนไทน์ (14.2) | สินค้าของขวัญ |
| เมษายน | สงกรานต์ | สินค้าเดินทาง/ท่องเที่ยว |
| มิถุนายน-กรกฎาคม | Mid-Year Sale (6.6, 7.7) | ลดราคากลางปี |
| สิงหาคม | 8.8 | แคมเปญลดราคา |
| กันยายน | 9.9 | แคมเปญลดราคา |
| ตุลาคม | 10.10 | แคมเปญลดราคา |
| พฤศจิกายน | 11.11 (Double 11) | แคมเปญใหญ่ที่สุดรองจาก 12.12 |
| ธันวาคม | 12.12, ปีใหม่ | แคมเปญใหญ่ที่สุดของปี |
```

**หลักการสำคัญ:** แพลตฟอร์ม E-Commerce (Shopee, Lazada) มักจัดแคมเปญพิเศษในวันที่ตัวเลขซ้ำกัน (Double Date) ทุกเดือน ควรวางแผนเข้าร่วมทุกครั้งที่เป็นไปได้ เพราะแพลตฟอร์มมักเพิ่มการมองเห็นสินค้าที่เข้าร่วมแคมเปญ

## Step 482: การวางแผนแคมเปญล่วงหน้า

### Timeline การเตรียมตัวสำหรับแคมเปญใหญ่ (เช่น 11.11)
```markdown
6-8 สัปดาห์ก่อน: วางแผนสินค้าที่จะโปรโมท คำนวณส่วนลดที่คุ้มค่า
4 สัปดาห์ก่อน: สั่งสต๊อกสินค้าเพิ่ม (ถ้าเป็น Reseller/Private Label) เตรียมภาพ/คอนเทนต์โปรโมท
2 สัปดาห์ก่อน: เริ่มสร้างความคาดหวัง (Teaser) ในโซเชียลมีเดีย
1 สัปดาห์ก่อน: ตั้งค่าโปรโมชันในระบบแพลตฟอร์ม ตรวจสอบสต๊อกครั้งสุดท้าย
วันแคมเปญ: ติดตามยอดขายและตอบแชทอย่างใกล้ชิด (คนมักถามคำถามมากช่วงนี้)
หลังแคมเปญ: วิเคราะห์ผลลัพธ์และวางแผนติดตามลูกค้าใหม่ (Step 488)
```

## Step 483: การคำนวณโปรโมชันที่ไม่ทำให้ขาดทุน

### สูตรตรวจสอบก่อนตั้งส่วนลด
```
กำไรหลังหักส่วนลด = ราคาขายเดิม × (1 - % ส่วนลด) - ต้นทุนทั้งหมดต่อหน่วย (Part 046 Step 453)

ตัวอย่าง:
ราคาขายเดิม: 300 บาท ต้นทุนทั้งหมด: 180 บาท (กำไรปกติ 120 บาท)
ลด 20% → ราคาขาย = 240 บาท
กำไรหลังหักส่วนลด = 240 - 180 = 60 บาท (กำไรลดลง 50%)
```

**หลักการสำคัญ:** ก่อนตั้งส่วนลดทุกครั้ง ต้องคำนวณว่ากำไรที่เหลือยังคุ้มค่าหรือไม่ ถ้ากำไรลดลงมากเกินไป ให้พิจารณากลยุทธ์อื่นแทนการลดราคาตรงๆ (เช่น Step 485)

## Step 484: การใช้เครื่องมือโปรโมชันของแพลตฟอร์มอย่างมีประสิทธิภาพ

### เครื่องมือโปรโมชันที่แพลตฟอร์มมักมีให้ใช้
| เครื่องมือ | อธิบาย |
|---|---|
| **Flash Sale** | ลดราคาช่วงเวลาจำกัด สร้างความเร่งด่วน |
| **คูปองส่วนลด** | ให้ลูกค้ากดเก็บคูปองก่อนใช้ กระตุ้นการมีส่วนร่วม |
| **แถมของแถม (Free Gift)** | เพิ่มมูลค่าโดยไม่ต้องลดราคาสินค้าหลักตรงๆ |
| **ส่งฟรีเมื่อซื้อครบ (Free Shipping Threshold)** | กระตุ้นให้ซื้อเพิ่มเพื่อให้ครบเงื่อนไข เพิ่ม AOV |

**เทคนิค:** การใช้ "ส่งฟรีเมื่อซื้อครบ" มักได้ผลดีกว่าการลดราคาตรงๆ เพราะกระตุ้นให้ลูกค้าซื้อเพิ่มโดยที่กำไรต่อหน่วยไม่ลดลง

---

## Step 485: เทคนิคเพิ่มยอดขายช่วงเทศกาลนอกเหนือจากการลดราคา

1. **Bundle สินค้า** — จับสินค้าหลายชิ้นขายเป็นแพ็คเกจราคาพิเศษ เพิ่ม AOV โดยไม่ต้องลดราคาต่อชิ้นมาก
2. **จำกัดจำนวนสินค้าโปรโมชัน** — "ลดราคาเฉพาะ 50 ชิ้นแรก" สร้างความเร่งด่วนแบบจริง
3. **สร้างคอนเทนต์ก่อนแคมเปญ** — ใช้ทักษะจากหมวด C เตรียมโพสต์/วิดีโอ Teaser ล่วงหน้า
4. **ใช้ Live Commerce** — ไลฟ์ขายสินค้าช่วงแคมเปญเพื่อตอบคำถามสดและสร้างความเร่งด่วน

## Step 486: การเตรียมสต๊อกและกำลังคนสำหรับวันแคมเปญ

### เช็กลิสต์เตรียมความพร้อมวันแคมเปญ
```markdown
- [ ] ตรวจสอบสต๊อกสินค้าเพียงพอสำหรับยอดขายที่คาดการณ์ (ประมาณจากปีก่อน/แคมเปญที่ผ่านมา)
- [ ] เตรียมวัสดุแพ็คสินค้าให้พร้อมมากกว่าปกติ
- [ ] วางแผนเวลาตอบแชทให้ครอบคลุมช่วงพีค (มักเป็นช่วงเที่ยงคืนของวันแคมเปญ)
- [ ] เตรียมคำตอบ FAQ เกี่ยวกับโปรโมชันให้พร้อม (เงื่อนไข, วันหมดเขต)
```

## Step 487: การวิเคราะห์ผลลัพธ์แคมเปญหลังจบ

```markdown
ยอดขายรวม: ___________

เทียบกับเป้าหมายที่ตั้งไว้: ___________
สินค้าที่ขายดีที่สุด: ___________
สิ่งที่ควรปรับปรุงในแคมเปญถัดไป: ___________
```

## Step 488: การรักษาลูกค้าใหม่ที่ได้จากแคมเปญ

ลูกค้าที่มาซื้อเพราะโปรโมชันมักไม่ภักดีกับร้านถ้าไม่มีการติดตามต่อ

### กลยุทธ์รักษาลูกค้าหลังแคมเปญ
1. **ส่งข้อความขอบคุณพร้อมเชิญติดตามช่องทางโซเชียลมีเดีย/LINE OA** (เชื่อมโยง Part 007)
2. **เก็บข้อมูลเพื่อทำ Email/LINE Marketing ในอนาคต** (เชื่อมโยง Part 027, 036)
3. **เสนอส่วนลดเล็กๆ สำหรับการซื้อครั้งที่สอง** เพื่อกระตุ้นการซื้อซ้ำ

## Step 489: กรณีศึกษา — แคมเปญ 11.11 ที่วางแผนล่วงหน้าจนยอดขายเพิ่ม 5 เท่า

**สถานการณ์:** ผู้เรียนคนหนึ่งเข้าร่วมแคมเปญ 11.11 ครั้งแรกโดยไม่ได้วางแผนล่วงหน้า แค่ลดราคาสินค้าทั้งหมด 20% ยอดขายเพิ่มขึ้นเพียงเล็กน้อยเทียบกับวันปกติ

**การปรับปีถัดมา:** วางแผนตาม Timeline Step 482 ทำ Bundle สินค้าขายดี 3 ชิ้นในราคาพิเศษ สร้าง Teaser คอนเทนต์ล่วงหน้า 2 สัปดาห์ และเตรียมสต๊อกเพิ่มขึ้น 3 เท่าจากปกติ

**ผลลัพธ์:** ยอดขายวัน 11.11 เพิ่มขึ้น 5 เท่าเทียบกับวันปกติ และมากกว่าแคมเปญปีก่อนถึง 3 เท่า เพราะการวางแผนล่วงหน้าและสร้างความคาดหวังก่อนวันจริง

**บทเรียน:** ความสำเร็จของแคมเปญเทศกาลไม่ได้มาจากการลดราคามากที่สุด แต่มาจากการวางแผนล่วงหน้าอย่างเป็นระบบ ตั้งแต่สต๊อก คอนเทนต์ ไปจนถึงการจัดการวันจริง
